# 1.项目设计
```
需要开发一个todo的mcp，支持：
  1. 提供增删改查task的接口
  2. 提供增删改查全年目标的接口
  3. 数据保存在sqllite中
  4. 使用npx运行

  请帮我完善这个设计
  
  task字段：任务ID、关联目标ID（可为空）、标题、描述、AI处理建议、标签（编码/文 
  档写作/问题处理/会议等）、状态（待处理/done/doing）、优先级（高/中/低）、创建 
  时间、截止时间、责任人(本人/AI)、进展、结果、完成时间                               
  goal字段：目标ID、标题、描述、目标周期、评价标准、权重占比、AI处理建议、完成时间、结果、自评   
```

# 2.使用
```
配置这个mcp
```
